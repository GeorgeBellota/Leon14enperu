# assets/docs/

Carpeta reservada para los documentos descargables del sitio. Está vacía a
propósito: todavía no existe ninguno.

Cuando los haya, aquí van y desde aquí los enlaza la sección **Vive la visita**
(`index.html#vive-la-visita`):

| Archivo previsto | De dónde sale |
|---|---|
| `guia-del-peregrino.pdf` | Se publica junto con el programa oficial |
| `guia-de-oracion.pdf` | Materiales de pastoral de la CEP |
| `kit-parroquias.zip` | Banners, fondos de pantalla y avatares |
| `kit-de-prensa.zip` | Sala de prensa, cuando exista |

Al añadir uno: sustituir el `href="#"` del acceso correspondiente, quitarle
`data-pending="true"` y `aria-disabled="true"`, e indicar formato y peso en el
texto del enlace («PDF · 1,2 MB»), que es lo mínimo que agradece quien está en
una conexión móvil.
